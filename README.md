# VPN Telegram WebApp Bot

Telegram WebApp bot for managing self-hosted VPN access.

Features:

- Telegram WebApp user/admin panel
- Xray VLESS Reality
- AmneziaWG / AmneziaWG 2.0
- AWG QR code and latest handshake status
- SOCKS5 / Dante proxy
- Telegram MTProto Proxy
- SQLite storage
- systemd + nginx deployment

Main documentation:

- [Русский README](README_RU.md)

## Security

Never commit `.env`, SQLite databases, logs, VPN private keys, MTProto secrets or production configs.
